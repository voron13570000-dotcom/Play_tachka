# Тачка Невозврата Online — MVP

Это самостоятельный веб-прототип multiplayer-версии по правилам, которые были видны на присланных фотографиях.

## Уже работает
- комнаты по коду;
- 2–6 игроков;
- цель 3 или 5 млн ₽;
- стартовые 150 000 ₽;
- онлайн-синхронизация через Socket.IO;
- игровое поле и фишки;
- бросок кубика;
- стоимость перемещения: 1–2 бесплатно, 3=30k, 4=60k, 5=100k, 6=300k;
- покупка машин 4 типов;
- гараж;
- ремонт;
- продажа;
- прокат;
- таксование;
- гонка как игровой режим-заготовка;
- аукцион;
- долги;
- автоматическая проверка победителя.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открыть http://localhost:3000

Для игры по интернету сервер нужно разместить на VPS/Render/Railway/Fly.io и открыть HTTPS.
